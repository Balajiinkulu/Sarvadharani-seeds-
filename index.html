Total Dr should equal Total Cr — if not, it's usually a sign an Opening Balance was entered inconsistently somewhere. This does not include the value of stock on hand as a ledger figure, since stock is tracked separately in the Stock reports.

Start New Financial Year
ⓘ This takes every party's and account's CURRENT closing balance (shown above) and sets it as their new Opening Balance, dated from the day you choose below. It does not delete, hide, or lock any past voucher — every past entry stays fully visible, editable, and deletable exactly as before. It only changes where each ledger's running balance "starts counting from" going forward. You can always undo this manually afterwards by editing a party/account's Opening Balance and Opening Balance As Of date back in Alter Party / Accounts.

Invoice Number Gap Check

ⓘ Every voucher number is generated as SDS/<year>/<prefix>/<number>, counting up by exactly 1 each time within its own financial year — so under normal use each series should run 1, 2, 3… with no holes. A hole almost always means a voucher was deleted after it had already been numbered (deleting a voucher never renumbers the ones after it). This is worth keeping clean for your own records, and in case a tax officer ever asks why a number is missing.
